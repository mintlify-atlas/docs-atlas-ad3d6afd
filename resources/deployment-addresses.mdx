## Overview

The DeployableVM contract is deployed using a deterministic deployment strategy with an empty salt, ensuring consistent addresses across networks where possible. All deployments are verified on their respective block explorers.

<Note>
  All contracts are deployed using CREATE2 with an empty salt for deterministic addresses.
</Note>

## Verifying Deployments

You can verify the deployment address before deploying to a new network:

```bash
forge script 'script/DeployableVM.s.sol:DeployableVMScript' -vvvv --rpc-url "$ETH_RPC_URL" --private-key "$PK"
```

<Warning>
  Ensure you're using the correct Foundry toolchain version (`cb9dfae298fe0b5a5cdef2536955f50b8c7f0bf5`) to generate the same deterministic addresses.
</Warning>

## Deployment Source

The deployment addresses are automatically generated from deployment artifacts. You can find the source data in the [`networks.json`](https://github.com/cowprotocol/weiroll/blob/main/networks.json) file in the repository.

## Adding New Networks

To deploy to a new network:

1. Set the required environment variables:
   ```bash
   export ETHERSCAN_API_KEY='your API key here'
   export PK='deployer private key'
   export ETH_RPC_URL='https://rpc.node.url'
   ```

2. Deploy and verify:
   ```bash
   forge script 'script/DeployableVM.s.sol:DeployableVMScript' -vvvv \
     --rpc-url "$ETH_RPC_URL" \
     --private-key "$PK" \
     --verify --broadcast
   ```

3. Update the networks file:
   ```bash
   bash dev/generate-networks-file.sh > networks.json
   ```

<Info>
  All deployments use CREATE2 with an empty salt for deterministic deployment.
</Info>
