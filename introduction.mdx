## What is Weiroll?

Weiroll provides a runtime scripting engine for Ethereum smart contracts. Instead of hardcoding complex logic into your contracts, you can define execution plans as sequences of commands that are executed by the Weiroll VM.

The `DeployableVM` contract in this repository wraps the Enso Finance audited Weiroll VM implementation, making it available as a singleton that can be used via `delegatecall` from any contract.

<Info>
This implementation builds on the pioneering work of the [original Weiroll project](https://github.com/weiroll/weiroll) and the innovative [Enso Finance fork](https://github.com/enso-finance/enso-weiroll).
</Info>

## Use Cases

Weiroll is ideal for scenarios where you need flexible, composable on-chain logic:

- **DeFi protocols** that need to execute complex multi-step operations
- **Account abstraction** implementations requiring flexible execution logic
- **DAO governance** systems with dynamic proposal execution
- **Cross-chain bridges** and protocols requiring complex state transitions

## Getting Started

  <Step title="Install Foundry">

  </Step>

  <Step title="Integrate the VM">
